# 📚 Proyecto Biblioteca

Este proyecto es una aplicación en **C#** que implementa Programación Orientada a Objetos (POO) para gestionar una pequeña biblioteca de libros.  
Fue desarrollado como parte de la asignatura en la **Universidad Tecnológica de Costa Rica (UTC)**.  

## 🚀 Funcionalidades
- Clase `Libro` con propiedades:
  - `Titulo` (string)
  - `Autor` (string)
  - `Año` (int, validado como positivo)
- Constructor que inicializa todos los atributos.
- Método `MostrarInformacion()` que presenta la información de cada libro en consola.
- Programa principal que crea una biblioteca con al menos **5 libros diferentes** y muestra sus datos.

## 🖥️ Ejemplo de salida
📖 "Cien años de soledad"
Autor: Gabriel García Márquez
Año: 1967
📖 "1984"
Autor: George Orwell
Año: 1949
